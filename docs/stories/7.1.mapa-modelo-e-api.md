# Story 7.1 — Modelo e API do Mapa

**Status:** Implementada — migration **não aplicada** em produção (aguarda aprovação)

## Decisão
- `MapaOrigem` (`mapas_origem`): nasce anônimo em `/mapa`, ganha dono no pagamento. Token
  público `mo` + 24 [a-z0-9] na URL. Conteúdo em JSON validado (schema da 7.2).
- `MapaCredito` (`mapa_creditos`): pagamento sem Mapa vinculado vira crédito de resgate.
- O bloqueio é do servidor: antes do pagamento a API devolve só a capa. Depois, lê o
  conteúdo o dono logado **ou** o aparelho que gerou (cookie httpOnly `mapa_dispositivo`,
  guardado como sha256) — é quem volta do checkout sem login.
- Limite de custo no próprio banco (Redis é opcional no deploy): 5 Mapas/h por IP (hash com
  sal), 5/h por aparelho, 5/dia por telefone. Mesmo aparelho + nome + sintoma em 24 h reaproveita.
- Mapa de usuário excluído fica sem dono (`SET NULL`), não bloqueia a exclusão da conta.
- As rotas do Mapa aceitam sessão com troca de senha pendente (`allowPasswordResetRequired`), e
  `fetchClient` não desvia `/mapa*` para `/trocar-senha`: quem acabou de pagar lê o Mapa primeiro.
