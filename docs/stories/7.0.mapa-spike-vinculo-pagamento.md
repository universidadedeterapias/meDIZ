# Story 7.0 — Spike: o pagamento do Mapa acha o Mapa?

**Status:** Bloqueada — depende de uma compra teste na Guru (fora do app)

Plano: `docs/plano-mapa-origem-emocional.md` (Epic 7).

## Contexto
O botão "BAIXAR MEU MAPA" leva ao checkout Guru, que cobra pela Pagar.me/Stone. O pago
chega em `/api/stone/webhook`, mas não se sabe se algum parâmetro do link do checkout volta
no payload. Sem isso o pagamento não sabe qual Mapa desbloquear.

## O que já está pronto para o teste
- O checkout sai com `?src=<token>&utm_content=<token>` (`checkoutComToken`, Story 7.4).
- O webhook procura o token (`mo` + 24 [a-z0-9]) **no payload inteiro**, sem depender do
  nome do campo (`extrairTokensDoPayload`). Se o token voltar em qualquer lugar, funciona.
- Plano B automático: telefone do checkout = `?id=` do link da Aline (DDD + 8 últimos dígitos).
- Plano C automático: crédito de 1 Mapa na conta, resgatado em `/mapa/resgatar`.
