# Story 7.4 — Página pública `/mapa`

**Status:** Implementada

## Decisão
- `/mapa`: quiz de 5 passos do protótipo `1_gerar.html` (nome, sintoma, há quanto tempo,
  3 momentos + idade, acontecimento com pai/mãe). Só nome e sintoma travam. Lê `?s=`
  (sintoma), `?id=` (telefone) e `utm_*`. Sem login, sem menu, sem voltar global.
- Gerar leva para `/mapa/<token>`, uma URL só para o ciclo inteiro (sobrevive a recarregar):
  gerando (animação de 4 etapas, polling de 2 s) → erro com "tentar de novo" → bloqueado
  (protótipo `2_pronto_bloqueado.html`) → pago (Mapa aberto).
- "BAIXAR MEU MAPA" abre o checkout em **outra aba** e a página fica perguntando a cada 4 s
  (e ao voltar para a aba): quando o Pix cai, ela vira o Mapa sozinha. Se o navegador bloquear
  a aba, vai na mesma.
- Oferta e preço por env (`NEXT_PUBLIC_MAPA_CHECKOUT_URL`, `NEXT_PUBLIC_MAPA_PRECO`) para o teste
  de preço sem deploy de código. Padrão: `mapa-p1-1490`, R$ 14,90.
- Capa do produto servida do próprio app (`public/mapa/capa.webp`, 15 KB), não da CDN da Hotmart.

## Critérios de aceite
- [x] Quiz igual ao protótipo, sintoma pré-preenchido pelo link (conferido em 390 px)
- [x] Bloqueado mostra só a capa; corpo borrado é decoração
- [x] Checkout com token no link
- [ ] Teste ponta a ponta depois da migration (gerar → pagar → ler)
- [ ] Eventos de funil (link aberto, passo do quiz, gerado, clicou baixar) — fica para a 7.9
