# Story 7.8 — Link do Mapa para a Aline (n8n + ChatVolt)

**Status:** Implementada em teste (18/10). A Aline está só no chat de teste; o link dá 404 até o deploy do app.

## Decisão
- A IA não informa o telefone. Ela manda só `conversationId` + `sintoma`, e o n8n busca o
  telefone na conversa da ChatVolt (`GET /conversation/<id>` → `participantsContacts[].phoneNumber`).
- O webhook sempre responde 200. Se não achar o telefone, o link sai só com o sintoma: o
  pagamento ainda acha o Mapa pelo código do checkout.

  `POST /webhook/mapa-link` → `{ link, tem_telefone, instrucao }`, em ~0,6 s.

  (`cmveilf6m1dkw11wwh5valy9h`), corpo cru `{conversationId, sintoma}`, no máximo 2 chamadas.
- Prompt E5: "Aceitou → chame gerar_link_mapa…" no lugar do marcador `[AJUSTE FINAL — CHAMAR FERRAMENTA…]`.
